6. 관리자 기능 및 콘텐츠 수정 방법

별도의 관리자 로그인 기능은 포함하지 않았습니다(정적 콘텐츠). 텍스트·이미지는 아래 파일을 수정한 뒤 GitHub에 반영하면 자동 배포됩니다.

수정 항목파일
회사 정보·연락처·메뉴·빈 버튼 연결 경로src/config/site.ts
About 페이지 문구(소셜미션, 팀, 연혁, 인증, 대외활동)src/data/about.ts
Products 페이지 문구(문제, 기능, 라인업, 비교표, IP)src/data/products.ts
메인 영상 파일public/videos/mobility.mp4, public/videos/employment.mp4
이미지public/images/ (logo, product, photo, team, cert, activity, illust)
운영 도메인.env.production 의 NEXT_PUBLIC_SITE_URL
